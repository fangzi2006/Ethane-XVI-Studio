# Ethane-XVI Studio 桌面版开发与通信协议文档

本文档基于原 `Ethane-XVI-QT` C++/Qt 上位机、`Ethane-XVI上位机说明.pdf` 及 `Ethane-XVI-CH549` 固件源码整理，包含硬件布局、USB Custom HID 通信协议（含扩展的 Flash 回读与 `RBSY` 忙保护机制）、二进制数据结构定义以及 **Tauri v2 + Rust (`hidapi`) + React** 分层架构说明。

---

## 1. 硬件拓扑与物理布局

Ethane-XVI 是基于 WCH CH549 主控的复合 HID 编程小键盘，根据 `PCB.png` 实体布局如下：

- **顶部功能区（从左到右）**：
  1. **摇杆（RK1）**：双轴模拟摇杆（ADC 0~4095）+ 下压微动按键
  2. **旋钮 2（EC2）**：靠中间的旋转编码器（逆时针/顺时针/下压按键）
  3. **USB-C 接口 & 系统 RGB 指示灯（LED1）**：用于配置标签色提示及 Num/Caps/Scroll/连点/按键组状态复用指示
  4. **旋钮 1（EC1）**：最靠右侧边缘的旋转编码器（逆时针/顺时针/下压按键），下方为无源蜂鸣器（BUZZER1）
- **主体按键区（4 × 4 矩阵）**：
  - 16 颗机械按键 `K1 ~ K16`（从左到右、从上到下排列），每颗按键配备独立 WS2812 RGB 彩灯。

## 2. USB 设备描述符与接口规划

- **Vendor ID (VID)**：`0x1A86`（十进制 `6790`）
- **Product ID (PID)**：`0x5884`（十进制 `22660`）
- **Product String**：`Ethane-XVI`
- **Manufacturer String**：`Light&Electricity`
- **Serial Number**：12 位大写十六进制芯片唯一 ID（可用于区分多台设备）

| Interface | 端点 | UsagePage | 报告长度 | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| Interface 0 | EP2 IN | `0x01` / `0x0C` / `0x0D` | 22B | 主 HID（键盘、鼠标、媒体控制、Surface Dial） |
| Interface 1 | EP3 IN | `0x0D` | 7B | 触摸屏 HID（绝对坐标光标移位/点击） |
| Interface 2 | EP4 IN/OUT | `0xFF01` | 64B | RGB Custom HID（SignalRGB 实时灯效帧 `0xA5 0x5A 0x03 ...`） |
| **Interface 3** | **EP1 IN/OUT** | **`0xFF00`** | **64B** | **上位机配置与控制 Custom HID（Windows `hidapi` 写入前置 `0x00` Report ID，共 65B）** |

## 3. Custom HID 通信协议（UsagePage `0xFF00`）

通信采用**请求-响应（Command-Response）**模式，单包有效载荷固定 **64 字节**（Rust `hidapi` 后端在 Windows 下发送前自动前置 `0x00` Report ID 拼为 65B，读取时自动剥离首字节 `0x00`）。
- 非法命令统一回复：`['R', 'I', 'N', 'V', ...]`
- 固件忙保护回复：`['R', 'B', 'S', 'Y', ...]`（当 CH549 主循环正在执行异步 Flash 擦写 `asyncFlag != 0` 时，USB 中断拒绝新命令以保护共享缓冲区 `FlashBuf[512]`；上位机协议层 `transactCommand` 收到 `RBSY` 后自动间隔 `15ms` 重试，最多 30 次）
- 合法命令响应头部：首字节为 `'R'`，第 1~3 字节原样回显请求命令字。
- 多字节整型（`u16` / `u32`）在 CH549（8051 内核）与协议中均采用 **大端字节序（Big-Endian）**。

### 3.1 配置写入命令（多包传输与写入校验）

| 命令 | 请求包格式 | 响应与后续流程 |
| :--- | :--- | :--- |
| 键盘配置写入 | `'D','K','B','C', slot('1'..'8')` | 收到 `'R','K','B','C'` 后，分 **8 包**（每包 64B，间隔 `2ms`）发送 512B；每包回复 `'R','D', idx(0..7)`；末包后短暂等待 `30ms` 并依赖 `RBSY` 自动同步落盘，随后执行 `BRKC` 逐字节回读校验 |
| 灯效配置写入 | `'D','L','T','C', slot('1'..'8')` | 收到 `'R','L','T','C'` 后，分 **4 包**（每包 64B，间隔 `2ms`）发送 256B；每包回复 `'R','D', idx(0..3)`；末包后短暂等待 `20ms` 并依赖 `RBSY` 自动同步落盘，随后执行 `BRLC` 逐字节回读校验 |

### 3.2 配置回读命令（方案 B 扩展，兼容旧固件自动降级）

为实现真正的“一键从设备读取当前配置”，在 `Ethane-XVI-CH549/User/CompositeHID.c` 中新增 3 条无状态只读指令（若旧固件返回 `RINV`，上位机自动降级为从本地缓存恢复）：

| 命令 | 请求包格式 | 响应包格式 | 说明 |
| :--- | :--- | :--- | :--- |
| 当前槽位读取 | `'B','C','S','I'` | `'R','C','S','I', slot('1'..'8')` | 读取当前激活的配置槽位 |
| 键盘配置回读 | `'B','R','K','C', slot('1'..'8'), chunk(0..15)` | `'R','R','K','C', slot, chunk, data[32]` | 每次读 32B，共 16 包拼出完整 512B（越界时 `[4]=0xFF`） |
| 灯效配置回读 | `'B','R','L','C', slot('1'..'8'), chunk(0..7)` | `'R','R','L','C', slot, chunk, data[32]` | 每次读 32B，共 8 包拼出完整 256B（越界时 `[4]=0xFF`） |

### 3.3 全局参数与设备读写命令（单包传输）

| 命令 | 请求载荷 | 响应载荷 | 说明 |
| :--- | :--- | :--- | :--- |
| `CKYT` | `[4]=debounce(u8, 0..100)` | `[4]=old, [5]=new` | 设置按键后延迟消抖参数（立即写 Flash） |
| `CRKM` | 无 | `[4..7]=oldMid0/1, [8..11]=newMid0/1` (u16 BE) | 将当前摇杆 ADC 采样值设为中位 |
| `CRKZ` | `[4..11]=min0,max0,min1,max1` (u16 BE) | `[4..11]=old, [12..19]=new` 或 `[12..13]=0xFFFF` 拒绝 | 设置摇杆范围（需 `min < mid < max`） |
| `CECD` | `[4]=ec1Freq(0/1), [5]=ec2Freq(0/1)` | `[4..5]=old, [6..7]=new` | 设置旋钮 1/2 倍频（2 脉冲编码器设 1） |
| `BFWV` | 无 | `[4..7]=v0,v1,v2,v3` | 读取固件版本 `V a.b.c.d` |
| `BUID` | 无 | `[4..9]=6B UID` | 读取 12 位大写十六进制唯一序列号 |
| `BIPT` | 无 | `[4..7]=adcX/Y(u16 BE), [10..11]=ec1/2(u8), [12..15]=keyMask(u32 BE)` | 实时读取摇杆、旋钮计数与 19 键位图 |
| `BGPM` | 无 | `[4..59]=56B 全局参数`（偏移见 4.3 节） | 读取全局参数 |
| `BDGC` | 无 | `[4..59]=56B 诊断统计`（28 × u16 BE） | 读取看门狗重启、Flash 错误计数等 |
| `BRST` | 无 | `'R','R','S','T'` | 软复位 |
| `BBOT` | 无 | `'R','B','O','T'` | 擦除首扇区进入 Boot 预跳转（重新拔插进入刷机模式） |
| `BCSC` | `[4]=slot('1'..'8')` | `[4]=oldSlot, [5]=newSlot` | 立即切换设备生效配置槽 |
| `BBUZ` | 无 | `'R','B','U','Z'` | 进入蜂鸣器演奏模式 |
| `BBTV` | `[4]=note(0..48), [5]=vol(0..10)` | `'R','B','T','V'` | 蜂鸣器实时发声测试（音量 0 静音） |

## 4. 二进制配置数据格式

### 4.1 键盘配置（512 字节 / `.etcfg` / 8 套）

- **`[0..467]` 按键变长区**（16 颗按键顺序紧凑排列，总长 ≤ 468B）：
  - 每颗按键以 `id(1..16)` + `mode(0..9)` 开头：
    - `0 无`：0B
    - `1 单键`：`key(1B)`
    - `2 快捷键`：`key(1B) + func(1B)`（`func`: `bit0=Ctrl, bit1=Shift, bit2=Alt, bit3=Win`）
    - `3 按键组（宏）`：`len(1B) + data[len]`（单键 ≤ 255B）
      - 单键：`key(1B)` | Shift+键：`250, key` | 快捷键：`253, key, func`
      - 光标移位/点击：`236/237, xH, xL, yH, yL` | 延时：`254, tH, tL`
      - 循环：`235, func(0x02起始 / bit0自动), nH, nL` | 报文控制：`234, func(bit1=End, bit0=Gap)`
    - `4 光标移位` / `5 光标点击`：`xH, xL, yH, yL`
    - `6 切换键`：`key(1B) + func(1B)`（`bit7=1` 临时 / `0` 永久，`bit3..0 = 1..8` 目标槽位）
    - `7 按键连点`：`key(1B) + func(0按住/1自动) + tH, tL`
    - `8 蜂鸣器`：0B
    - `9 摩尔斯码`：`func(高4位音量0..10, 低4位: 0点/1划/2单键) + tGap(10ms) + tLong(10ms)`
- **`[468..479]` 摇杆（12B）**：
  - `468`：`rockerMode(0..4) | (keyMode(0..3) << 4)`
  - `469`：`dir`（`bit0=X反, bit1=Y反, bit2=右旋90°`）
  - `470..474`：5 个键值（中心、上、下、左、右）
  - `475`：中心按键 `func`
  - `476`：死区（0~200）
  - `477..479`：惯性参数(0~50)、近端参数(0~50)、远端参数(0~50)（光标位置模式下复用为中心 X、中心 Y、范围缩放）
- **`[480..495]` 双旋钮（2 × 8B，480=旋钮1, 488=旋钮2）**：
  - `+0`：`rotateMode(0..2) | (keyMode(0..3) << 4)`
  - `+1`：反向（`bit0`）
  - `+2..+4`：按键、逆时针、顺时针键值
  - `+5..+7`：按键、逆时针、顺时针 `func`
  - *Dial 旋转模式编码*：旋转角 `(1..100°) = 左键数字(0..9)*10 + 右键数字(0..9) + 1`，插值 `(1..5)` 由左键 `func` 编码（无=2, Ctrl=1, Shift=3, Alt=4, Win=5）。
- **`[496..505]` 系统指示灯（10B）**：
  - `496..498`：标签色 RGB；`499..501`：指示亮度 RGB
  - `502..504`：R/G/B 映射（`bit7=反向, bit3..0 = 0无/1Num/2Caps/3Scroll/4连点/5按键组`）
  - `505`：高 4 位亮起时间（0~7），低 4 位渐灭速度（0~4）
- **`[506..511]` 系统参数（6B）**：
  - `506..507`：屏幕宽（u16 BE）；`508..509`：屏幕高（u16 BE）
  - `510`：键盘旋转方向（`0正常/1右旋90°/2旋转180°/3左旋90°`）
  - `511`：总优先级（`1=是, 0=否`）

### 4.2 灯效配置（256 字节 / `.etlight` / 8 套）

- `0..47`：上配色 16×RGB；`48..95`：下配色 16×RGB
- `96..111`：单键按下渐变(0~30)；`112..127`：单键抬起渐变(0~30)；`128..143`：单键屏蔽剩余(0~255)；`144..159`：单键自定义次序(0~15)
- `224..232`：循环/随机模式列表（9 项，每项 `0..5`）；`235`：有效项数 - 1（`0..8`）
- `238`：配置切换策略（`0切换/1不切换/2临时保持`）；`240`：动作方向（`0..7`）；`241`：动作模式（`0..7`）
- `242`：变色设置（`0不变/1上变/2下变/3上下变`）；`243`：变色周期（秒，0~255）
- `244..245`：等待时间（u16 BE，单位 **10ms**）；`246..247`：动作时间（u16 BE，ms）；`248..249`：间隔时间（u16 BE，ms）；`250..251`：随机间隔（u16 BE，ms）
- `252..255`：亮渐变、灭渐变、屏蔽亮渐变、屏蔽灭渐变（0~30）

### 4.3 全局配置（`BGPM` 返回的 56 字节）

- `[0..1]` Min0、`[2..3]` Min1、`[4..5]` Max0、`[6..7]` Max1、`[8..9]` Mid0、`[10..11]` Mid1（均为 u16 BE）
- `[16]` 按键消抖参数（u8）
- `[20]` 旋钮倍频参数（`bit0=EC1, bit1=EC2`）

### Rust 后端高性能收发设计（`src-tauri/src/lib.rs`）
- **单所有权直通线程**：打开设备后由专用后台线程独占 `HidDevice`，空闲时阻塞在 `mpsc::Receiver::recv()`（零 CPU 占用），收到请求后 0ms 延迟立即 `write` + `read_timeout`，彻底规避 Windows 15.6ms 定时器粒度造成的轮询空等。
- **批量事务指令（`hid_transact_batch`）**：`BRKC`（16 包）与 `BRLC`（8 包）各合并为单次 Rust IPC，在原生线程内紧贴 CH549 的 `1ms` USB 轮询周期连续收发，整机 8 层 IPC 往返从 192 次降至 16 次。
